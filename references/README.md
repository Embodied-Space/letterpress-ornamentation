# References

A knowledge base of material that informs the design and the implementation. Add things over time.
Before designing or building something, check here first.

## What belongs here
- Photos and scans of the ornament pieces, the spacing material and printed proofs
- Measurements and notes on the piece geometry (line thickness, line spacing, where the line sits in each body)
- Specimen sheets and catalog pages
- Example layouts and design inspiration
- Code snippets or other tools worth borrowing from
- Transcripts and notes from conversations or research

## Suggested subfolders
Create a subfolder the first time you need it:
- `images/`: photos, scans, proofs, inspiration
- `measurements/`: dimension notes for the pieces and spacers
- `code/`: reference code and snippets
- `transcripts/`: conversation and research notes
- `docs/`: specimen sheets, articles, PDFs

## Conventions
- Use descriptive file names, e.g. `images/corner-block-front.jpg`.
- If a reference is tied to a spec, mention the spec number in the file name or in a note next to it.
